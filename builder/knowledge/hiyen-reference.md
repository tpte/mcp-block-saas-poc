# HIYEN 型後台參考（非綁死實作）

HIYEN 在 MATRIX 裡代表「多模組公司後台」範例，典型包含：

- **人力**：請假表、核准流程（hr 模組）
- **財務**：現金流、發票列表（finance 模組）
- **營運**：工單、庫存、銷售管道（support / inventory / sales）
- **檢視**：週 KPI、渠道組成（analytics）

使用者若要「自己做類似 HIYEN」：

1. 不必複製全部模組；先選與其業務最相關的 2～3 塊。
2. 先建立資料源計畫（哪怕尚未連線）。
3. 用 hiyen-starter 模板還原「常見模組組合」，再逐項關閉或改名。
